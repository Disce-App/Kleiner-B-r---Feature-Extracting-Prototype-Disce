# Gamma-Inventur — Research-Framework

## Zweck

Systematische Bestandsaufnahme aller verfügbaren Open-Source-Bausteine (Modelle, Libraries, Korpora, Tools), die für die **German-Disce-Speech-Suite** relevant sind.

**Prinzip:** Erst alles auf den Tisch legen (Gamma), dann komponieren (Beta), dann das Produkt definieren (Alpha).

---

## Steckbrief-Schema (pro Baustein)

Jeder identifizierte Baustein wird nach diesem Schema erfasst:

| Dimension              | Leitfrage                                                                 |
|------------------------|---------------------------------------------------------------------------|
| **Name & Typ**         | Was ist es? (Modell / Library / Korpus / Pipeline / Toolkit)              |
| **Quelle**             | Wer steckt dahinter? (Organisation, Repo-URL, Lizenz)                    |
| **Deutsch-Tauglichkeit** | Wie gut funktioniert es für Deutsch? Gibt es de-DE-spezifische Varianten? |
| **Lerner-Tauglichkeit**  | Wurde es auf L2-Speech / akzentbehaftete / fehlerhafte Sprache getestet?  |
| **Granularität**       | Welches Auflösungsniveau? (Satz / Wort / Phonem / Frame / Feature)        |
| **Output-Format**      | Was kommt raus? (Text, Alignment, Score, Embedding, Annotation, …)        |
| **Integration**        | Wie einbettbar? (Python-API, CLI, ONNX, HuggingFace, REST, …)            |
| **Compute**            | Ressourcenbedarf? (GPU-Typ, VRAM, Latenz, Edge-/CPU-fähig?)              |
| **Reife**              | Produktionsreife? (Research-Prototype / Beta / Production-Grade)          |
| **Limitationen**       | Was kann es explizit *nicht*?                                             |

## Arbeitsablauf pro Domäne

```
1. SAMMELN      Alle relevanten Bausteine identifizieren (breite Suche)
2. STECKBRIEF   Jeden Baustein nach Schema oben erfassen
3. LÜCKEN       Was fehlt für unseren Use Case? Was gibt es für EN, aber nicht für DE?
4. NOTIZ        Kombinatorik-Hinweise für Beta (nur Stichworte, kein Design)
5. VERDICT      Welche Bausteine kommen in die engere Wahl — und warum?
```

---

## Zusätzliche Erfassungsdimensionen (pro Domäne, nicht pro Baustein)

### Landkarte
> Welche Bausteine existieren insgesamt in dieser Domäne? (Vollständigkeitsanspruch)

### Lücken
> Was fehlt — insbesondere: was existiert für Englisch, aber nicht (oder kaum) für Deutsch?
> Was existiert für Muttersprachler, aber nicht für Lerner?

### Kombinatorik-Notiz (Vorgriff auf Beta)
> Welche Bausteine sind natürliche Paare oder Pipeline-Nachbarn?
> (Nur Stichworte — Beta-Design kommt später)
